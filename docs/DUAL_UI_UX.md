# 듀얼 UI/UX 구조 문서

## 개요

점글이 앱은 보호자/교사와 시각장애인 학생 모두를 만족시키는 **듀얼 UI/UX 구조**를 제공합니다.

## 1. 홈 화면 (듀얼 구조)

### 보호자용 시각 UI

홈 화면은 4개 핵심 모듈로 구성됩니다:

1. **오늘 학습 이어하기 카드**
   - 현재 학습 중인 교재 및 진행도 표시
   - 지문/문항 완료 수 표시
   - "계속하기" 버튼

2. **과목 선택 카드**
   - 국어/영어/수학 카드 UI
   - 각 과목별 오늘 학습량 표시

3. **교재 관리 카드**
   - PDF 업로드 버튼
   - 최근 업로드된 PDF 목록 및 분석 상태
   - 진행률 표시

4. **점자 디바이스 연결 카드**
   - BLE 연결 상태
   - 배터리 잔량
   - 연결/해제 버튼

### 시각장애인용 음성/점자 UX

- **음성 안내**: 페이지 진입 시 현재 학습 상태 자동 안내
- **음성 명령**:
  - "이어하기" → 학습 이어가기
  - "국어 시작" → 국어 학습 시작
  - "수학 시작" → 수학 학습 시작
  - "영어 시작" → 영어 학습 시작

## 2. 학습 화면 (3단 패널 구조)

### 보호자용 시각 UI

**왼쪽 패널 - 문서 구조 트리**
- 지문/문항 계층 구조 표시
- 현재 청크 하이라이트
- 클릭으로 청크 이동

**가운데 패널 - 현재 출력 중인 내용**
- 현재 청크 텍스트 표시
- 진행도 바
- 그래프 미리보기 (그래프 패턴인 경우)

**오른쪽 패널 - 점자 출력 상태**
- 현재 점자 셀 시각화 (6-dot 패턴)
- 3-cell 패킷 미리보기
- 연결 상태 표시

### 시각장애인용 음성/점자 UX

- **TTS**: 현재 청크 자동 읽기
- **점자 디바이스**: 동일 청크 3-cell 패킷 출력
- **탐색 버튼**:
  - NEXT: 다음 청크
  - PREV: 이전 청크
  - REPEAT: 현재 청크 반복

## 3. 선택지 비교 모드

### 보호자용 시각 UI

**비교 테이블:**
| 선택지 | 핵심 주장 | 오류 유형 | 근거 문장 |
|--------|----------|-----------|-----------|
| ① | 전체 학생을 말함 | 조건 과확대 | "모든 학생은..." |
| ② | 일부 학생 의미 | 정확 | "일부 학생은..." |
| ③ | 시간 조건 누락 | 조건 누락 | "3년간..." |

- 정답은 초록색, 오답은 회색으로 표시

### 시각장애인용 음성 UX

- 선택지 클릭 시 음성 설명:
  - "① 전체 학생이라고 말하지만, 지문에서는 일부 학생을 말합니다. 따라서 단서 불일치입니다."
- 점자 출력: 핵심 키워드 및 오류 유형

## 4. 그래프 모드

### 보호자용 시각 UI

**왼쪽: 그래프 원본 + 분석 결과**
- 그래프 이미지
- 분석 결과 (추세, 극값, 증감 구간)
- 의미 설명

**오른쪽: 점자 패턴 미리보기**
- 그래프 패턴별 점자 셀 표시
- 패턴 설명

### 시각장애인용 음성/점자 UX

- **음성**: "그래프는 처음에 완만히 증가합니다."
- **점자**: 증가 패턴 출력
- **NEXT 버튼**: 다음 패턴 (극대값, 감소구간 등)

## 5. 상태 동기화

### 실시간 동기화

1. **청크 변경**: 보호자 화면과 점자 디바이스 동시 업데이트
2. **점자 출력**: 보호자 화면에 점자 셀 시각화 표시
3. **학습 진행**: 양쪽 모두 진행도 동기화

### 기술 구현

- **프론트엔드**: Zustand store로 상태 관리
- **BLE 통신**: Web Bluetooth API로 실시간 점자 출력
- **TTS**: Web Speech API로 음성 안내

## 6. 접근성 기능

### 키보드 네비게이션
- 모든 버튼은 키보드로 접근 가능
- Tab 순서 최적화

### 스크린 리더 지원
- ARIA 레이블 및 역할 정의
- 상태 변경 알림

### 고대비 모드
- 설정에서 고대비 모드 활성화 가능

## 7. 사용 시나리오

### 시나리오 1: 보호자와 함께 학습

1. 보호자가 PDF 업로드
2. 보호자가 화면에서 분석 진행 상황 확인
3. 학생은 점자 디바이스로 학습
4. 보호자가 화면에서 점자 출력 내용 확인
5. 보호자가 필요 시 도움 제공

### 시나리오 2: 독립 학습

1. 학생이 음성으로 "국어 시작" 명령
2. 앱이 TTS로 안내
3. 점자 디바이스에 첫 청크 출력
4. 학생이 NEXT 버튼으로 탐색
5. 필요 시 REPEAT 버튼으로 반복

### 시나리오 3: 선택지 비교

1. 학생이 문항 풀이 중
2. 보호자가 화면에서 선택지 비교 테이블 확인
3. 학생이 선택지 번호를 음성으로 말함
4. 앱이 해당 선택지 설명을 TTS로 제공
5. 보호자가 필요 시 추가 설명
